## white-crumpled-sheet.png prompt

Use case: product-mockup. Create a photorealistic UI texture asset: a single blank PURE WHITE sheet of ordinary thin printer paper that was tightly crushed into a ball and carefully opened flat again. Front-facing orthographic overhead view, portrait 3:4 proportions, sheet fills the frame edge to edge. Real dense irregular crumpling: fine branching creases, subtle angular dents, overlapping shallow folds, small sharp highlights and neutral light grey occlusion shadows. White paper stays bright white, no beige, no yellow, no parchment, no stains. Soft neutral studio lighting from upper left. Flat enough for dark text to be overlaid legibly, but visibly crumpled across the entire sheet. No text, no ruled lines, no objects, no decorative effects, no regular geometric/repeated pattern. Output one high resolution photographic texture.
